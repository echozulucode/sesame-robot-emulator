QEMU is a separate program. Sesame Lab starts it as its own operating-system
process and talks to it over a TCP socket; nothing in Sesame Lab links against
it. Sesame Lab's own code is licensed under the Apache License 2.0
(Sesame-Lab-LICENSE-Apache-2.0.txt).

The four ESP32 boot ROM images installed beside it under qemu\share\qemu\ are
Espressif silicon ROM dumps, not part of QEMU. QEMU's own LICENSE file
(QEMU-LICENSE.txt) states that such firmware blobs are separate programs under
separate licences.

WHY AN OFFER AND NOT ONLY A DOWNLOAD LINK
-----------------------------------------

Section 3 of GPL-2.0 offers three ways to accompany a binary with its source.
3(c) — passing along an offer you yourself received — is unavailable here: the
Espressif release that this binary came from carries no such offer, so there is
nothing to pass along. That leaves 3(a), shipping the source alongside, and
3(b), this offer.

Publishing the source archive on the same page as the installer is the closest a
download-based distribution gets to 3(a), and it is the intended primary
mechanism. GPL-2.0 was written for physical media, and whether same-page
availability satisfies "accompany" for a network download is genuinely contested,
so this offer is the backstop — and it is the only thing that covers a copy
handed over on a USB stick, or a chat attachment, or any other route that never
touches the release page.

WHY THE TAG IS THE CORRESPONDENCE
---------------------------------

This executable was not compiled by Sesame Lab. It is Espressif's own published
build, downloaded by emulator/qemu/fetch-qemu.mjs and verified byte-for-byte
against the SHA-256 manifest Espressif publishes with that same release — so
which release this binary came from is provable rather than asserted. The source
at tag esp-develop-9.2.2-20260417 is the source Espressif builds it from.

Building QEMU from that tag yourself is the only way to make the correspondence
exact, because Espressif's MinGW cross-toolchain and build flags are part of its
own repository rather than part of this application.

For the full analysis, see docs/findings/LICENSE-AUDIT.md section 3 in the
Sesame Lab repository.
